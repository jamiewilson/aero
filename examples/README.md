# Examples

- **[kitchen-sink](kitchen-sink/)** — Full demo app with content collections, Nitro API, Alpine.js, and HTMX. From that directory: `vp dev --open`, `vp build --mode ci`, etc. ([README](kitchen-sink/README.md)).
- **[import-bundling](import-bundling/)** — Import and bundling demos (single-bundle, cdn-globals, esm-import-map, cdn-externals, dynamic-import). Each subproject uses `client/` for pages and assets. See [import-bundling/README.md](import-bundling/README.md) and [Importing and bundling](../docs/guide/importing-and-bundling.mdx).
- **[integrations/aero-lume](integrations/aero-lume/)** — Minimal Aero + [Lume](https://github.com/sathvikc/lume-js) client binding example. See [README](integrations/aero-lume/README.md).
